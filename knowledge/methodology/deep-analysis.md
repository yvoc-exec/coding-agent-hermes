# Deep Analysis for Hard Engineering Problems

Trigger only on important contradictions, causally ambiguous cross-boundary bugs, repeated meaningful failures, costly architectural choices or actual stagnation. Create an evidence matrix: observed fact and source; plausible explanation; prerequisite; falsifying observation; smallest discriminating test; expected risk/cost. Compare at least two materially distinct explanations when alternatives exist. Map identities, event order, persistence and error propagation. Check whether outputs were stale, executed in the wrong process, produced by a mock, or reflect version mismatch.

Return one prioritized new test or a grounded blocker, not another generalized search. Do not repeat deep analysis for unchanged evidence. Prefer a narrow authoritative document over speculative API names.
