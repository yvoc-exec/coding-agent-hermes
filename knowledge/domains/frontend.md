# Frontend and UI

Trace user event -> component/view-model -> state/context/store -> request -> rendering and accessibility. Consider SSR/CSR boundaries, hydration, stale caches, asynchronous races, abort/cancellation, keyboard semantics, responsive behavior, i18n and XSS/sanitization. Favor actual user-observable regression over snapshot-only assertions. Validate build and targeted interaction tests where supported; do not invent screenshots or visual acceptance.
