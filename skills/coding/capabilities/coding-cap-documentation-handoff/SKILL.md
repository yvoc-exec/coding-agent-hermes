# Technical Documentation and Delivery

Explain the documented behavior actually implemented, not proposed. Update minimal README/config/API docs affected by the change; give usable commands verified against repo scripts and environment when possible. Provide reproduction, expected and observed results, compatibility notes and operator-controlled rollout. Include remaining unknowns honestly and redact secrets/identifiers. For handoff keep precise file paths, symbols, unresolved blockers, tested commits only when actually known, and project-local Workspace links. Avoid long transcripts that obscure the next action.

Read the owning Domain or Methodology when the concrete task triggers it. Preserve operator scope and explicit test evidence.
