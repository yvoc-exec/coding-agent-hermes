# Build, CI and Portable Runtime

Identify actual language/toolchain versions, build graph, environment variables, test runners, container context, caching and CI job dependencies. Read scripts/workflows before running; classify local-vs-CI differences, permissions and file generation. Prefer deterministic builds, reproducible tools and exact version contracts. Never change secrets, hosted CI settings, registry publication or deployment without explicit approval. Verify static workflow syntax where supported and report any CI-only unknowns.

Read the owning Domain or Methodology when the concrete task triggers it. Preserve operator scope and explicit test evidence.
