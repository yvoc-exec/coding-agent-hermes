# Agent, LLM and Tool-Calling Integration

Map provider/model route, context assembly, policy instruction hierarchy, tool discovery/schema, dispatch, persisted session, subagent boundaries and failure/retry flow. Distinguish provider response, tool invocation, asynchronous task completion, and verified side effects. Test quota/timeout/model changes, prompt injection, context compaction, concurrent state writes, tool authorization and output integrity. Reuse native agent framework features rather than inventing wrappers. Record observability gaps accurately and use synthetic secret fixtures.

Read the owning Domain or Methodology when the concrete task triggers it. Preserve operator scope and explicit test evidence.
